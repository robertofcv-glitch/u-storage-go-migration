# U-Storage Go runtime assets — v1

This directory contains the production web subset curated from Brand Package v1.0:

- variable Montserrat WOFF2 files for the web (400–700, normal and italic)
- static Montserrat Regular and SemiBold TTF files for reliable PDF embedding
- official logo signatures and reverse variants
- approved digital marks and favicon sizes
- customer-facing outline and duotone SVG icons

The authoritative, unchanged package remains in `brand/source/`. Application code must reference this versioned runtime directory and must not import source-package files.
